# Proyecto Godot

Abre `project.godot` en Godot **4.6.3** y pulsa F5.

La escena inicial es `playable/game.tscn`: aventura 2D completa de tres lugares, combate en tiempo real, compañero, jefe y rescate. Código: `playable/game.gd`. Arte: `playable/assets/`, adaptado de los sprites del prototipo original. No hay plugins ni assets remotos.

Los módulos de la base anterior se conservan para consulta. No forman parte del recorrido de la nueva partida. La información de los controles, exportación y pruebas está en el [README principal](../README.md).
